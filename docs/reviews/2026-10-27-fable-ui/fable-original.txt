# 匿名科研个人网站设计评审

## 1. 整体诊断

这是一个结构清晰、工程上相当克制的原生站点：单字体（Source Sans 3）、声明过的四级字号尺度、带年份悬挂的论文列表、有键盘与焦点管理的图库灯箱、天气页独立的 CSS 变量和空状态处理，这些都是成熟站点的底子。**最值得保留的**：① 纸面暖色底 + 半透明面板的浅色基调（01）；② 论文列表的年份—标题—元数据三层结构（02）；③ 天气页的信息层级（标题/状态行/双栏/日报带/出处）与可访问性细节（aria-pressed、role=status、44px 控件）；④ 图库的年份锚点、全景跨列与 content-visibility 性能处理；⑤ 把"天气"作为个人兴趣的产品化表达——它与插画里的天气骰子是同一条叙事线。

核心问题不在单个页面，而在**两套气质并存**：内容层是"温暖纸面学术"，背景层却是"黑底星空 + 橙色城市灯光 + 绿极光"的太空影像（06），且 script.js 默认主题为 dark。加上细碎字号、多种圆角、胶囊与 emoji 过多，整体显得比内容本身"热闹"。下面的建议围绕"把背景降回配角、把 token 收紧、把个人温度交给插画"展开。

## 2. 优先建议

**R1 · P1 · 背景体系与默认主题**（06、01/02/03/05；styles.css `.space-earth-canvas`、`html.has-cinematic-earth-bg`；script.js `activeTheme`）
直接证据：每页加载 three.js 渲染星空地球；浅色下 canvas 以 8% 透明叠在 0.72 透明面板之后，截图中可见一道弧形灰带横穿 Selected works 面板；深色下黑底、橙色灯光、青色脉冲标记、绿极光。设计判断：这与用户要求的低饱和暖色插画语言直接冲突，也是全站最高饱和的元素。改法：默认跟随 `prefers-color-scheme`、无记录时取浅色；浅色完全不加载 three.js；深色改为静态深蓝灰底（见第 3 节），若想保留"地球"意象，用一张与插画同手法的静态夜景图替代。性能收益待验证，但移除 CDN 脚本与 55 万次粒子采样的方向是确定的。

**R2 · P1 · 字号/圆角 token 失控**（styles.css 注释声明 32/20/16/14，实际存在 .8/.82/.84/.86/.9/.95/1.14/1.6rem；圆角 8/10/12/13/14/16）
直接证据。影响：用户明确反感的"大小字号混乱"主要来自这些 0.8–0.95rem 的细碎元数据与图库年份标题。改法：全站收敛为 32/24/20/16/14（地图版权 12 例外），圆角 6/12/16 + 胶囊，见 token 表；删掉 `.weather-slot/.weather-line` 等无对应元素的死 CSS（index.html 中无 `#weather-line`）。

**R3 · P1 · Hero 留白与装饰密度**（01、07；`.hero-wrap{align-items:stretch}`、`.portrait-card{min-height:100%}`）
直接证据：文本卡被肖像卡撑高，按钮下方约四分之一空白；三个地球 emoji 折到两行；一屏内有眉标、3 个标签、4 个图标钮共 8 个胶囊；移动端肖像卡 430px 几乎独占一屏。改法：`align-items:start`；About 的 facts 行上移进 hero 填充；field-tags 改为一行灰字"Atmosphere · Wind power · Scientific ML"；社交链接改为"图标+文字"的文本链接行（RG 字标与其他线性图标风格不一）；副标题去 emoji；移动端肖像按 3:2 裁切、高度 ≤240px。

**R4 · P1 · 导航信息架构与吸顶态**（01 vs 02；07/08/09；`.site-nav` overflow-x + mask；`.site-header.is-stuck .header-inner{display:flex}`）
直接证据：7 项导航中 5 个锚点与 2 个独立页交错排列；390px 下 Weather、Gallery 两个最独特的页面恰好被截断；吸顶时导航从品牌下方跳到右侧，布局发生位移。改法：Referee service 并入 Publications 面板作 h3，Contact 移至 hero 链接行与页脚，导航减为 About · Research · Publications ｜ Weather · Gallery；吸顶态只改背景/阴影不改排布；≤560px 允许换行两行而非横向滚动（5 项能否单行待验证）。主题切换钮 22px 命中区偏小，建议 36px 以上。

**R5 · P2 · 正文可读性**（01；`.panel p{color:var(--muted)}`）
设计判断：传记正文使用次要色，行长约 1000px（约 140 字符）。改法：正文用 `--ink-soft`，`max-width:70ch`；muted 只用于元数据。对比度未测量，不作 WCAG 结论。

**R6 · P2 · 天气地图的饱和度与遮挡**（03、08；`core.temperatureColor` YlOrBr 渐变；`.wx-layers [aria-pressed=true]`）
直接证据：市区站点标签重叠（"3" 被遮、31° 叠压 29°），OSM 标准瓦片的粉色道路、亮绿公园与站点的黄—深红标签是全站最高饱和区域；切换钮选中态仅边框变化。改法：`.leaflet-tile-pane{filter:saturate(.45) contrast(.95)}`（地名可读性待验证）；初始视图聚焦主要站点，"Show all stations" 展开全图，或仅选中/悬停显示数值标签，其余用 10px 圆点；数据渐变改为低饱和顺序色（#efe8d8→#c9a27a→#8f4f3c→#4a2a28，保持单调亮度梯度以保证可读序）；分段控件选中态用 accent 实色填充 + 白字。

**R7 · P2 · GNN 暖机态**（04；`#wx-gnn-controls`、`#wx-map-notice` 已定义但此态未用）
直接证据（仅评已见状态）：关键信息"输入历史 83%"是 14px 次要文字，禁用控件与可用态差异小，下方 460px 空地图无图例。改法：在地图上方渲染状态条——一句话 + `<progress value=83 max=100>`；无数据时地图高度降至 240px 或淡显站点位置；禁用控件 `opacity:.5`。ready 态体验未见，建议上线后按同一状态条样式验证"已签发 · 10 分钟步长"信息是否够显眼。

**R8 · P3 · 图库层级**（05、09；gallery.js 年/组计数始终同时渲染；`@media(hover:hover)` 标题仅悬停显示）
直接证据：标题面板只有两行却占一整块；单组年份下"5 photos"重复出现；桌面标题藏在悬停层，触屏却在图下，两端信息不一致；年标题 1.6rem 游离于尺度外。改法：页标题改为无面板页头；年份计数仅在多组时显示；标题/日期统一显示在图下（14px muted）；年=20px、组=16px 半粗；移动端改 2 列（8px 间距）以减少滚动。实际数量与分类不作断言。

## 3. 统一视觉方向："纸面工作室"

一套字体、两种字重（400/600，可去掉 500/700 以减少字体请求）、一种青灰强调色、一种木色暖色，其余全部交给留白与插画。

| 类别 | 取值 |
|---|---|
| 字体 | Source Sans 3 全站；无衬线替代 Avenir Next/Helvetica Neue |
| 字号/行高 | 页标题 32/1.2 · 分区 24/1.3（仅 h1 之下的大分区，可省略）· 面板标题 20/1.4 · 正文 16/1.6 · 元数据 14/1.5 · 地图版权 12 |
| 浅色 | --bg #f6f3ee · --surface #fdfcfa（面板不透明度 ≥0.94）· --ink #243236 · --ink-soft #3a4a4f · --muted #65757a · --line rgba(36,50,54,.14) · --accent #3b6e73 · --accent-tint rgba(59,110,115,.10) · --warm #a0795a · --warn #b8862f |
| 深色 | --bg #161c20 · --surface #1f272c · --ink #e6ebec · --muted #a3b0b4 · --line rgba(230,235,236,.12) · --accent #8fbdbf · --warm #c9a98a |
| 删除 | --accent-2 黄色（facts 圆点、chip 悬停边框、btn-primary 渐变、深色 selection） |
| 间距 | 4 基数：8/12/16/24/32/48；面板内边距 32（移动 20）；面板间距 24；大分区 48 |
| 圆角 | 6 控件 · 12 卡片/地图/图片 · 16 面板 · 999 仅眉标 |
| 阴影 | 浅色 0 1px 2px rgba(36,50,54,.05), 0 8px 24px rgba(36,50,54,.06)；深色 0 1px 2px #0006, 0 12px 28px #0008；主要靠 1px 边线分层 |
| 图标 | 1.5px 线性 SVG，18/20px，currentColor；标题中不用 emoji；研究卡的 SVG 图标可换成与肖像同手法的小幅手绘点缀，每面板最多一处 |
| 背景动效 | 静态渐变 + 3% 的 40px 网格；可保留按天气做 60s 缓慢色温过渡（现有 data-weather 机制）；reduced-motion 下关闭；不再使用 canvas |

备选"暮色书房"：深色仍用上表 token，但以一张静态的插画夜景（同一办公室、窗外海湾夜灯）作 hero 肖像的深色版本，让日夜切换成为插画叙事而非背景引擎切换。待验证：插画是否能提供两版。

## 4. 页面布局建议

**首页** 桌面：hero 两栏 7:5，`align-items:start`；左栏依次为眉标（可改为无胶囊的 14px 暖色文字）、姓名 32、一句话、facts 行、链接行；右栏插画卡按 4:5 固定比例。若实际插画为横幅（待验证），改为上图下文的通栏，文字块向上压 32px 叠在图底。建议恢复 hero 中的一行小字天气（weather.js 已具备），放在插画卡下沿，与天气骰子和 Weather 页形成呼应。Research 三卡保留但去阴影、只留边线，避免"卡中卡"。移动端：姓名→3:2 插画（≤240px）→一句话→链接行；Research 改为带小图标的列表。

**图库** 桌面：无面板页头（标题 32 + 一行年份文字链接），3 列 16px 间距，组标题 16 半粗 + 右侧计数 14；标题日期固定在图下。移动端：2 列 8px 间距，网格不显示标题，灯箱内显示完整标题；年份锚点行可 `position:sticky` 于导航之下（可选）。

**天气** 桌面：维持 1.55:1 双栏，右栏 `position:sticky; top:72px; align-self:start`，使文字预报在滚动地图时可见；"Refresh weather" 移至状态行右端，与"更新于 … HKT"并列；日报详情三栏改为 `auto auto 1fr`，避免"Rain chance"被推到最右。移动端：标题下直接状态行 + 刷新；地图 320px；日报带每屏 3.5 张（现已如此，保留切边作为滚动暗示）。

## 5. 三阶段实施

| 阶段 | 内容 | 可观察验收 |
|---|---|---|
| **一 · 快速整理（CSS 为主）** | R2 token 统一；R5 正文色与行长；去黄色圆点；面板不透明度；R3 的 `align-items:start` 与移动端肖像高度；默认主题改为跟随系统；浅色不加载 three.js；吸顶态保持同布局 | 全站 font-size 取值 ≤6 种、圆角 ≤4 种；01 文本卡底部空白 ≤24px；浅色截图无弧形灰带；390px 首屏能看到姓名与一句话；网络面板中浅色页面无 three.min.js |
| **二 · 中等改版（结构 + JS）** | R4 导航减项与换行；R3 hero 内容重组（facts、链接行、去 emoji）；R6 瓦片去饱和、标签避让、分段控件；R7 暖机状态条；R8 图库页头、计数、标题位置、移动端 2 列；恢复 hero 天气行 | 390px 导航无被截断项；1280px 初始视图站点标签无重叠；切换钮选中态在截图中可一眼辨认；暖机态首屏可见进度；图库页首屏出现首个缩略图 |
| **三 · 更大改版（视觉系统）** | 深色主题按新 token 重做并决定是否彻底移除 three.js；插画按实际比例接入 hero，日夜双版插画；手绘小图标替换研究卡 SVG 与 emoji；性能预算 | 浅/深两套截图共用同一组 token；首页除 Leaflet 外 JS 总量明显下降（阈值待实测确定）；深色页面不出现饱和橙/绿/青元素；reduced-motion 下无任何持续动画 |

总体而言，这个站点不需要推倒重来：内容层已经具备成熟学术站点的骨架，真正要做的是把背景从主角降为气氛、把尺度与装饰收紧，并让"个人温度"由插画与天气这两条已有的叙事线承担。
