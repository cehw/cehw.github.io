# Anonymous Fable city design — 2026-10-29

The user requested Fable 5.1 through the API to improve the light-mode city background. The official Anthropic API was called with `claude-fable-5-1`, adaptive thinking and `xhigh` effort. The credential was loaded from the existing Windows user environment, never copied into project files or review content.

## Input and privacy

The input comprised homepage/background CSS, the earlier decorative skyline SVG, a generic brief and an anonymous local screenshot. Names, institutions, biography, personal links, page metadata and analytics were removed or replaced. A geometric placeholder replaced the portrait. Actual photos, domain and private server paths were not sent.

## Adopted design

Fable supplied a complete layered SVG and light-only CSS: distant misty blue-grey buildings, warm stone structures, a small bridge and sage-green trees. The lower-viewport placement keeps the existing Earth visible and preserves the biography/portrait layout. A multiply blend and restrained opacity integrate the scene with the page; rainy conditions and narrow screens use lower opacity. The artwork is decorative, not a geographical representation.

The dark-mode pure black space background and original Earth rendering remain unchanged. The work affects the homepage only. The SVG was parsed and the actual desktop page was visually checked before publication. Raw anonymous prompts and API responses are retained only in the ignored project `_tmp/city-design/` directory.
