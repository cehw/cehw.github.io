# Website design

Desktop is the primary design target. The site combines the original animated Earth/weather background, translucent reading panels and the existing complete square illustration. The flat-background redesign was rejected by the user. `styles.css` owns shared typography, colors, navigation, panels and gallery presentation. `background.css` owns the restored background styling; `weather-dashboard.css` extends shared tokens for weather controls. Keep personal content intact when changing presentation.

## Visual system

Homepage-specific background refinements live in `homepage.css`, loaded only by `index.html`. Dark mode retains a pure black (`#000`) space background and the original Earth rendering. Reading panels, navigation and controls share the cleaner slate-blue palette across the homepage, weather and gallery pages. Shared surface tokens live in `styles.css`: dark panels use 70% opacity and light panels 64%, with an 8px backdrop blur to keep text readable. Secondary control surfaces use translucent blue-grey tints. Light mode retains the animated Earth and adds a layered, misty cityscape from `assets/city-outline.svg`: distant blue-grey buildings, warm stone accents, bridges and sage-green trees. The decorative vector artwork fades into the lower viewport; it is not a geographic map. The shared subtle street grid remains behind it. The city and light Earth artwork overrides remain homepage-only. The homepage has five circular social links, including GitHub.

## Fable review adoption

The [2026-10-27 review](reviews/2026-10-27-fable-ui-review.md) is a frozen record of anonymous external advice and verification. The retained recommendations are consistent typography, accessible navigation, clearer map labels, explicit GNN availability and simpler gallery hierarchy. The user rejected the removed background, narrow About text and mismatched hero proportions; those were corrected using the original desktop layout as the reference. The full weather dashboard remains a separate page; the user subsequently requested a compact Clear Water Bay weather line on the homepage. The illustration is not cropped, and observation coverage is not represented as forecast completion progress. These choices preserve the user's established preferences.

Review materials contain anonymous placeholders; real personal content and photos were used only for local visual verification. The [2026-10-29 city design](reviews/2026-10-29-fable-city-design.md) replaces the subsequent thin skyline with a layered SVG supplied by Fable 5.1 through the official API. The review input contained CSS, the previous decorative SVG and an anonymous layout screenshot with a geometric portrait placeholder. No actual identity text, photos or domain was sent. The adopted design uses bottom-aligned cover sizing, a restrained multiply blend and reduced opacity in rainy weather. Dark mode, Earth rendering and hero proportions are unchanged by this city update.
